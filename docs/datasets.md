# Training and Evaluation Datasets for Agentic Fine-Tuning

Comprehensive catalog of HuggingFace datasets for training models in tool-calling, agentic trajectories, task classification, and agentic evaluation.

## 3. Recommended Core Blend (Lamark)

For Qwen3.5-9B / Qwen3.6-35B-A3B agentic fine-tuning, the priority blend:

### SFT (primary training)
1. **Nemotron-SFT-Agentic-v2** — broadest agentic coverage, commercial-friendly, multi-turn tool-use
2. **qwen3.5-toolcalling-v2** — direct Qwen3 message format, 60K samples with reasoning + tool calls
3. **hermes-function-calling-v1** — our heritage, structured output + agentic JSON
4. **hermes_reasoning_tool_use** — 51K with ````thinking```` blocks, Atropos RL-aligned
5. **Qwen-3.6-plus-agent-tool-calling-trajectory** — Qwen 3.6 Plus trajectories, rejection-sampled

### SFT Agentic (native tool-call trajectories)
1. **Nemotron-Agentic-v1** — Interactive Agent subset
2. **telos-agent-trajectory-dataset** — dual representation, synthetic from Qwen3.5 Plus
3. **qwen3.5-toolcalling-v2** (jupyter agent subset) — code execution reasoning

### DPO / RLVR
1. **Nemotron-RL-Agentic-Function-Calling-Pivot-v1** — general function-calling preference
2. **Nemotron-RL-Agentic-Conversational-Tool-Use-Pivot-v1** — conversational tool-use
3. **Nemotron-RL-Agentic-SWE-Pivot-v1** — software engineering agents

### General Anchor (frozen, quarterly refresh)
1. **tulu-3-sft-mixture** — 940K general instruction
2. **tulu-3-sft-personas-code** — code instruction

### Evaluation
1. **openthoughts-tblite** — agent benchmark (Terminal-Bench Lite)
2. **Mozilla tool-calling evals** — intent classification for tool-use
3. **mcp-agent-trajectory-benchmark** — MCP-specific trajectory eval
